# Box Shadow Design

One of the main details implemented in this project was recreating the bold shadow effect from the original design using `box-shadow`.

This challenge helped me better understand how each value inside `box-shadow` works and how shadows can create depth and visual hierarchy without using extra elements.

```css
box-shadow: 0.5rem 0.5rem 0 var(--Gray950);
